# 平台上传信息

## 标题

**卡住你的不是想象力，是不知道它叫什么**

## Skill 名称

`motion-lexicon-reel`

## 一句话描述

15 秒、14 个动作、14 个名字：先知道它叫什么，才做得出第二个。

## 详细描述

这条片子的论点只有一句：**卡住人的不是想象力，是不知道这个动作叫什么**。

所以它不解释、不铺陈、不讲课：每 0.9 秒给一个动作、一个名字、一次当场演示。看见名字，才复述得出来；复述得出来，才能对设计师说、对 AI 说、对自己说——然后才做得出第二个。观众记不住十四个定义，但会记住十四个会动的名字。

`motion-lexicon-reel` 就是把这句话做成一条片子的完整工作流：**命名 → 标本 → 网格 → 节拍 → 成片**。

每张卡片只干一件事：给出这个动作的名字（中文 900 字重大字 + 英文 mono），在旁边用几何图形把同一个动作再演一遍，中间夹三条真实参数（时长 / 缓动 / 切点）。14 张卡片压进 15.8 秒，瑞士网格排版（96 px 边距、24 px 基线、一条左对齐线到底）、高饱和色块轮转、一层持续漂移的几何母题底纹、播放器式 HUD，片尾用 24 格母题墙收口。

它解决的不是「怎么做得好看」，是**「怎么先有办法把它说清楚」**——词表对了，后面无论是自己做、还是交给 AI 做，才有共同语言。

## 使用场景

**1 · 设计系统上线：把新的动作名同步给全公司**
系统改版常死在「说了但没人会用」。15 秒 14 个名字，比一页文档更快形成共同语言。用在全员会开场、规范文档首页、Figma 封面。

**2 · 对接外包 / 自由设计师：用片子代替需求文档**
客户说「要丝滑一点」、你说「要 premium」——都没用。把片子发过去，指着一个名字说「就要这个」。用在 brief 附件、比稿开场、修改意见。

**3 · 给 AI 提需求之前：先把词表建起来**
「做得高级一点」喂给模型等于没喂。同一条片子的词表可以当术语表粘进 prompt，也可以在片尾顺手给出。

**4 · 招聘与新人 onboarding**
新人第一天看懂「我们怎么动」，比读规范文档快。

**5 · 课程 / 工作坊开场**
先把 14 个名字发下去，再教参数怎么调——学员缺的常常不是审美，是词汇。

**6 · 提案 / 比稿暖场**
客户说不清想要什么时，让他从 14 个会动的名字里指一个。

**7 · 知识型社交内容**
「N 个动作，N 秒讲完」本身就是可发布的形态，不用额外剪辑。

## 受众

**核心：需要把动效「说清楚」的人**

| 群体 | 他们拿到什么 |
|---|---|
| 设计系统 / 品牌规范负责人 | 一套能传播的共同词表 |
| 动效设计师 | 把自己在做的事翻译成客户和团队听得懂的话 |
| 产品经理 / 交互设计师 | 提需求时不必再只说「要顺滑」 |
| 创意总监 / 广告代理 | 提案时用名字对齐客户的想象 |
| 创始人 / 市场 / 运营 | 做产品片、找外包、写 brief 时有现成词汇 |
| 用 AI 做视频的人 | 把「高级感」换成模型听得懂的词 |
| 讲师 / 课程作者 | 开场先给词表，后面才好讲参数 |

**不适合**：只想要一条氛围片、不需要概念的人；期待人物 / 剧情 / 实拍的人。

**为什么是这群人**：片子的产出物不是一条视频，是一套能复用的词。

|---|---|
