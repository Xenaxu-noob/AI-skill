# 平台上传信息

## 标题

**卡住你的不是想象力，是不知道它叫什么**

## Skill 名称

`motion-lexicon-reel`

## 一句话描述

15 秒、14 个动作、14 个名字：先知道它叫什么，才做得出第二个。

## 详细描述

这条片子的论点只有一句：**卡住人的不是想象力，是不知道这个动作叫什么**。

所以它不解释、不铺陈、不讲课：每 0.9 秒给一个动作、一个名字、一次当场演示。看见名字，才复述得出来；复述得出来，才能对设计师说、对 AI 说、对自己说——然后才做得出第二个。观众记不住十四个定义，但会记住十四个会动的名字。

`motion-lexicon-reel` 就是把这句话做成一条片子的完整工作流：**命名 → 标本 → 网格 → 节拍 → 成片**。

每张卡片只干一件事：给出这个动作的名字（中文 900 字重大字 + 英文 mono），在旁边用几何图形把同一个动作再演一遍，中间夹三条真实参数（时长 / 缓动 / 切点）。14 张卡片压进 15.8 秒，瑞士网格排版（96 px 边距、24 px 基线、一条左对齐线到底）、高饱和色块轮转、一层持续漂移的几何母题底纹、播放器式 HUD，片尾用 24 格母题墙收口。

它解决的不是「怎么做得好看」，是**「怎么先有办法把它说清楚」**——词表对了，后面无论是自己做、还是交给 AI 做，才有共同语言。

## 使用场景

用在：给团队同步动词 · 对接外包时代替需求文档 · 喂 AI 前先建词表 · 课程开场 · 提案暖场

## 受众

适合：设计系统负责人 · 动效设计师 · 提需求的产品经理 · 用 AI 做视频的人

## 技术规格

| | |
|---|---|
| 分辨率 | 1920×1080 |
| 帧率 | 30 fps |
| 时长 | 15.8 s（14 刀 × 0.9 s + 3.2 s 尾卡） |
| 音轨 | 原创 150 BPM 轻打击乐，落点与 14 个切点对齐 |
| 依赖 | HyperFrames CLI（`npx hyperframes`）、Node 22+、ffmpeg、Python 3（音频） |
| 不花钱 | 没有模型调用、没有素材库、没有付费 API |
