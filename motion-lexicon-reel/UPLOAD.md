# 平台上传信息

## 标题

**15 秒，把 14 个动作排成一部辞典**

## Skill 名称

`motion-lexicon-reel`

## 一句话描述

用纯代码做一条 15 秒高饱和快切短片：左栏是动作的名字和参数，右栏是那个动作的图形标本，每 0.9 秒一刀。

## 详细描述

`motion-lexicon-reel` 是一个「词表型短片」的完整工作流：**命名 → 标本 → 网格 → 节拍 → 成片**。

每一张卡片只干一件事：给出这个动作的名字（中文 900 字重标题 + 英文 mono），在旁边用几何图形把同一个动作再演一遍，中间夹三条真实参数（时长 / 缓动 / 切点）。14 张卡片压进 15.8 秒，每 0.9 秒一刀，整体是瑞士网格排版（96 px 边距、24 px 基线、一条左对齐线到底、两条结构线都承担职能）、高饱和色块轮转、以及一层持续漂移的几何母题底纹。

它解决的是「有词表、有体系、但讲不清」的问题：**观众记不住 14 个定义，但能记住 14 个会动的名字。**

## 适合

- 动效 / 交互设计体系的对外介绍（easing、stagger、morph 这类术语）
- 「N 个东西，N 秒讲完」的社交短视频
- 产品功能清单、组件库、图标库的 showreel
- 品牌片头 / 频道包装
- 教学：设计基础、剪辑语法、镜头语言
- 会议开场、提案暖场、课程章节页
- 任何「先建立共同词汇，再谈合作」的场景

## 不适合

- 叙事型影片（它没有人物、没有冲突、没有起承转合）
- 需要真人出镜或实拍素材的内容
- 需要旁白讲解的科普（这里没有口播）
- 需要精确还原产品 UI 的演示

## 技术规格

| | |
|---|---|
| 分辨率 | 1920×1080 |
| 帧率 | 30 fps |
| 时长 | 15.8 s（14 刀 × 0.9 s + 3.2 s 尾卡） |
| 音轨 | 原创 150 BPM 轻打击乐，落点与 14 个切点对齐 |
| 依赖 | HyperFrames CLI（`npx hyperframes`）、Node 22+、ffmpeg、Python 3（音频） |
| 不花钱 | 没有模型调用、没有素材库、没有付费 API |
