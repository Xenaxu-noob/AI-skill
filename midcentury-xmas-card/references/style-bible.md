# 风格册 · Mid-Century Modern（1950s 美式）

1950s 的美国圣诞卡：奶油色卡纸、六七个饱和色块、几何形状、无阴影的平涂、
大量留白，和一点"原子时代"的乐观——星芒、飞碟形、A-Frame 三角屋、锥形松树。

## 颜色

只允许这些。多一个色就散。

| 用途 | 名 | Hex | 出现位置 |
|---|---|---|---|
| 卡纸 | cream | `#F4EBD9` | 封面底、卡片底色 |
| 纸面（略亮） | paper | `#FBF4E6` | 画框纸边、火漆描边 |
| 墨 | ink / navy | `#2E3532` / `#1B2D36` | 木屋墙、正文标题 |
| 陶土红 | terra | `#D15627` / `#BC4A2E` | 屋顶、火苗、落款、火漆 |
| 芥末黄 | mustard | `#D99B26` / `#D6A12B` | 檐带、暖窗内衬 |
| 湖水蓝 | teal | `#2B8A96` / `#255C5B` | 标题、远树、玻璃 |
| 橄榄绿 | olive | `#7A863B` / `#4E5523` | 近树、门 |
| 暖光 | warm | `#F4C150` / `#F8CE78` | 窗、火 |
| 雪 | snow | `#EFE4CE` / `#DCD1B8` | 雪坡、脚印、烟 |

规则：

- **平涂，零渐变**。唯一的例外是"光"：窗口和火苗外面允许一层极淡的径向暖光（`#F8CE78` → 透明）。
- **不用纯黑**。最深的颜色是 `#2E3532`，比黑暖。
- **不用纯白**。最亮的是 `#FBF4E6`，比白黄。
- 相邻两块颜色必须有明度差；同色系不并置。

## 字体

| 用在哪 | 字体 | 字号 / 字距 |
|---|---|---|
| 封面标题 | Futura / Jost 800 | 78（900 画布）· 字距 8 |
| 年份、眉标 | Jost 500 | 30 · 字距 13；13 · 字距 .34em |
| 背面主标题 | Jost 500 | 50 · 字距 .22em（从 .34em 收紧） |
| 正文（信） | Fraunces Italic 400 | 40 / 行高 1.6 |
| 手写（称呼、落款、P.S.） | Caveat 400/500 | 52 / 42 / 34 |

- 封面字只有五行以内，全大写，几何无衬线，字距大——这是 1950s 海报的呼吸方式。
- 信必须是**衬线斜体**。斜体 = 手写，衬线 = 有时间感。
- 手写体只用于三个地方：TO 的名字、落款、P.S.。用多了就廉价。

## 几何

- 松树 = 三层等腰三角 + 一根方树干，所有树共用一个 `<g id="pine-tree">` 模板，靠 `fill` 换色。
- 星芒 = 4 条线 + 端点的圆点（原子时代符号），三种尺寸，散在天空。
- 木屋 = A-Frame 三角 + 平顶侧翼 + 芥末色檐带；檐带里再塞两个小三角做装饰。
- 窗 = 三角窗（阁楼、侧墙）+ 矩形窗（门边），里面填暖黄。
- 雪坡 = 一个椭圆，不加描边。
- 所有形状边缘干净，**不要描边**（除了刻意的 6px 雪线）。

## 版式

- 封面：上方 1/3 天空（星芒 + 烟），中间 1/3 木屋和树，下面 1/3 只有三行字。
- 背面：上半是图（拱形窗），下半是信。图与字之间留 35–60px。
- 页边距：左右各 ≈ 1/10 卡宽；上下不对称，字永远不要贴边。

## 动画语气

- **慢**：主体动作用 `power2.out` / `power3.out`，0.5–0.9 s；不要弹跳（除了爱心落印）。
- **有重量**：纸片、碎片、卡片都是"落"下来的，不是"飞"进来的——除了照片碎片，那是唯一一次"飞"。
- **停留要长**：封面停留 1.4 s 以上，背面读字留 6 s。贺卡不是广告，不需要每 0.5 秒一个刺激。
- 环境动效只做三样：落雪、窗光呼吸、火苗跳动。别再加。
