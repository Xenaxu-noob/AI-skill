# 交付前检查

## 内容

- [ ] 封面标题拼写正确，年份与背面日期一致。
- [ ] 五行信没有一行超过 26 个字符；任意一行换行后仍读得通。
- [ ] TO / FROM 的名字是真人称呼，不是占位符。
- [ ] 日期写成 `25 · 12 · 2026` 这种点分隔，不是斜杠。
- [ ] 卡面上**没有**原照片、没有水印、没有编号、没有系列名。

## 画面

- [ ] 任意暂停一帧，封面都是完整构图：星芒在上、木屋居中、三行字在下，没有半成品。
- [ ] 木屋长出来的过程中，任何一帧都是**完整的建筑轮廓**（被雪线挡着下半截），不是梯形屋顶。
- [ ] 翻面后 0.3 秒内画框已经落位，不会先看到一张白纸。
- [ ] 碎片拼完后没有 1px 接缝；柔光扫过时照片边缘不发灰。
- [ ] 爱心落印后，右下角那枚火漆与正文至少留 40px 间距。

## 声音

- [ ] 翻面音效与画面转动的起点差 < 150 ms。
- [ ] 整体响度 −16 ~ −19 LUFS，峰值不高于 −1 dBFS。
- [ ] 静音看一遍：所有信息都在画面上。

## 技术

- [ ] `ffprobe`：1080×1920、30 fps、15.000 s、H.264 + AAC。
- [ ] 用同一份源码重渲一次，`md5` 与上一版一致（落雪和碎片都用了固定种子）。
- [ ] 首帧不是黑屏；末帧停留 0.3 s 以上。
- [ ] 渲染日志里没有 `[pageerror]`。
