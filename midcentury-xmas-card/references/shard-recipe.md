# 碎片配方 · 25 块不规则碎片飞入

背面那扇拱形窗里的照片，不是淡入的，是**碎成 25 块再拼回来**的。

## 为什么不是 5×5 方格

方格看起来像"拼图"或"加载中的瓦片"，不像碎片。要让边缘是斜的，
把所有碎片的顶点**抖动**一下，但相邻碎片必须共用同一个顶点——否则拼完之后会有缝。

## 做法

1. 建一个 5×5 的顶点网格（6×6 个顶点），横 164、竖 176（照片 820×880）。
2. 每个内部顶点随机偏移 ±21px；四条边上的顶点只沿边抖动；四角不动。
   ```js
   for (let r = 0; r <= ROWS; r++) for (let c = 0; c <= COLS; c++) {
     let x = c * CW, y = r * CH;
     if (c > 0 && c < COLS) x += (rnd() - .5) * 42;
     if (r > 0 && r < ROWS) y += (rnd() - .5) * 42;
     grid[r][c] = { x, y };
   }
   ```
3. 每个单元取四个角 → 算外接矩形 → 建一个 `div`，位置和尺寸就是外接矩形，
   `background-position` 挪到外接矩形在照片里的位置，再用 `clip-path: polygon(...)` 裁成那个四边形。
   ```js
   d.style.left = x0 + 'px'; d.style.top = y0 + 'px';
   d.style.width = w + 'px'; d.style.height = h + 'px';
   d.style.backgroundPosition = `${-x0}px ${-y0}px`;
   d.style.clipPath = 'polygon(' + pts.map(p => `${p.x-x0}px ${p.y-y0}px`).join(',') + ')';
   ```
   因为相邻单元共用顶点，25 块刚好铺满 820×880，**落定后严丝合缝**。
4. 初始位置：从画面中心向外的方向上，推 560–940px，随机旋转 ±13°，缩到 0.72。
   拱形窗本身 `overflow: hidden`，所以碎片在窗外时是看不见的——不用做透明度淡入，
   飞进画框的那一刻自然出现。
5. 落定：`power2.out` 0.85 s，`stagger: { each: .02, from: 'random' }`。
   **不要用 `expo.out`**：它 0.2 s 就走完 85% 的路，中间那一帧 25 块已经挤在窗口里，看起来是糊的。

## 坑一：GSAP 缩放嵌套 SVG 会位移

`gsap.to(el, { scale: .5 })` 作用在一个**已经有 `transform` 属性的 `<g>`** 上时，
GSAP 会自己算一个 origin 再补一个 translate；如果 CSS 里又有 `transform-box: fill-box`，
两者会打架，元素能被甩出去上百像素（实测 0.4 倍缩放时中心偏了 267×505 px）。

三条解法，任选：

- 缩放改成补间 `transform` 属性：`attr: { transform: 'scale(.4)' }`（本模板的星芒、碎片都用这个）。
- 把要缩放的图形包一层 `<g transform="translate(x,y)">`，让它的局部原点正好是缩放中心。
- 干脆不缩放：用透明度 + 位移（本模板的窗、门廊、脚印）。

## 坑二：落定后的 1px 缝

卡片整体被 `#scaler` 缩放到 0.95556，25 个碎片的边界落在非整数像素上，会露出头发丝一样的纸色缝。

本模板的解法：在第 6.66 秒 `set` 成一张**整图**（`#picFull`，内容与拼合结果完全一致），同时隐藏碎片。
因为两张图逐像素相同，观众看不到切换，只看到缝消失。

```js
tl.set('#picFull', { opacity: 1 }, 6.66);
tl.set(shards, { autoAlpha: 0 }, 6.66);
```

（如果不需要缩放（比如输出 1080 恰好是画的 1:1），也可以省掉这一步。）

## 坑三：翻过来先是一张白纸

碎片到 6.35 s 才拼完，但卡片 5.06 s 就翻过来了。中间这 1.3 秒如果什么都没有，
观众会看到一张空白奶油纸。

解法：**画框先落位**——5.15 s 让拱形窗（纸边 + 投影）淡入，窗内是纸色；
5.35 s 碎片才开始飞。这样"翻过来 → 空窗 → 碎片填满"是三个明确的拍子。
