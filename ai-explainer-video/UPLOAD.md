# 平台上传信息

## 标题

**60 秒，把复杂的事讲清楚**

## Skill 名称

`ai-explainer-video`

## 一句话描述

把复杂概念做成 60–90 秒的旁白动画：脚本、分镜、AI 场景底板、角色字幕、成片与多语言切版。

## 详细描述

`ai-explainer-video` 是一个 60–90 秒解释型动画的完整工作流：一句话论点 → 10 段脚本 → 20–30 镜分镜 → 正面 AI 场景底板 → 代码角色/字幕 → 旁白、音乐、音效 → 16:9 / 9:16 成片与多语言切版。

适合 AI/技术概念、产品发布、B2B 销售、课程培训、媒体解释视频、企业内部培训。它不追求电影感，而是让不懂的人在 1 分钟内听懂，并且能批量做多语言、多比例版本。

不适合真人品牌片、精确产品 UI 演示、强依赖演员表演的内容。

## 适用场景

- AI / 技术概念解释：LLM、Agent、RAG、推理、Token、幻觉
- 创业公司 / 产品发布：60 秒讲清“我们是谁、解决什么、怎么做”
- B2B 销售 / 融资 / 展会：把 deck 压成 60 秒 teaser
- 媒体 / 视频论文 / 知识内容：长文、报告、新闻转视频
- 教育 / 课程 / 企业培训 / 合规 / 入职
- 品牌 / 公共传播 / 公益科普
- 多语言 / 多平台：1 个母版切 16:9、9:16、1:1

## 适用人群

适合：AI 产品市场 · 创始人 · 知识博主 · 广告/创意代理公司 · B2B 销售 · 企业培训 · 课程团队 · 媒体 explainer 团队 · 公益/公共部门。
