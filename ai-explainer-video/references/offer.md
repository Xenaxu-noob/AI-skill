# Offer, Scoping, and Revision Rules

## Offers

| Offer | Scope | Best for |
|---|---|---|
| Single 60 s explainer | Script, storyboard, 1 master, 1 cutdown, VO, captions | Launch, homepage, pitch |
| Series (4–6) | Shared style bible + reusable characters/props | Creator, brand, product line |
| Template license | Editable project + 1 example, no custom animation | Agency, internal team |
| Localization pack | New VO + captions + re-timed text on existing master | Global campaign |
| Cutdown pack | 9:16, 1:1, 15 s, 6 s hooks | Paid social |

## Inputs required

- One-sentence thesis.
- Audience and desired action.
- Script or source material.
- Brand colors/fonts/logo rules.
- Claims and legal constraints.
- Deadline, languages, aspect ratios.
- Existing assets (footage, screenshots, product UI).

## Outputs

- Master 16:9 (60–90 s).
- 9:16 and/or 1:1 recomposed.
- Script + storyboard + SRT + thumbnail.
- VO WAV and mix.
- Source project + asset folder.
- Cost log for any AI generation.

## Timeline (typical)

| Stage | Time |
|---|---|
| Brief + thesis | 0.5 day |
| Script + storyboard | 1–2 days |
| Plates + character/overlay | 2–4 days |
| VO + mix + captions | 0.5–1 day |
| Render + QA | 0.5 day |
| Revisions | 1–2 rounds |

## Revision rules

Included:

- text corrections;
- timing nudges;
- color/contrast fixes;
- one recomposition per aspect ratio.

Not included:

- new thesis or new script;
- new scenes after storyboard lock;
- new AI plate generation beyond the agreed count;
- new language beyond the agreed pack;
- re-rendering the whole film for a different aspect ratio without recomposition.

## AI generation budget

- Quote per successful call, not per attempt.
- Set a hard cap before starting.
- Generate 3 variants per plate; select 1.
- If a plate fails (people/text/UI/chair backs), regenerate or discard.
- Log actual charge; failed calls may not be charged.
- Never use a paid tool to test connectivity.

## Delivery checklist

- [ ] Master plays end to end.
- [ ] 9:16 version is recomposed.
- [ ] Captions are synced and readable muted.
- [ ] Loudness and true peak verified.
- [ ] All text inside cards.
- [ ] No AI gibberish or UI artifacts.
- [ ] Source files handed over.
- [ ] Cost log attached.
