# QA Checklist

## Text

- [ ] Every text block is inside its card/board/screen.
- [ ] Text is centered horizontally and vertically in the card.
- [ ] No text touches a border; padding ≥ 16 px.
- [ ] Text does not overlap a face, hand, phone, or busy detail.
- [ ] `MODEL NAME`-style long labels are ≤ 90% of the plaque width.
- [ ] One line ≤ 14 CJK chars or ≤ 42 Latin chars.
- [ ] Two-line maximum on screen; captions may be two lines.
- [ ] Text is axis-aligned; no text pasted onto an angled surface.
- [ ] First and last frames of a zoom are checked for clipping.
- [ ] Mobile 9:16 safe area verified (140 px top/bottom).

## Characters

- [ ] Arms visible on every human.
- [ ] Face has eyes with pupil/highlight, eyebrows, nose, mouth.
- [ ] Phone: audience sees the back, not the screen.
- [ ] Shoes: sole covers the pant-leg end; no dark cap below.
- [ ] Seated: body bottom is on the seat, not floating above/below.
- [ ] Chairs: backless where specified; no high-back chairs.
- [ ] Character feet/shadow touch the floor.
- [ ] No accidental robot reflection behind a character's head.

## Plates

- [ ] No people, faces, hands.
- [ ] No gibberish text, logos, watermarks.
- [ ] No floating UI cards or white panels.
- [ ] Main surface is frontal and rectangular.
- [ ] Chair seats visible; no backrests.
- [ ] Empty floor area for character placement.
- [ ] Plate color temperature matches the film.
- [ ] Right/left edges have no accidental white panel.

## Motion

- [ ] Hook reads by 0:03.
- [ ] 20–30 shots for 60–90 s.
- [ ] Hard cuts dominate; 4–6 white wipes at act changes.
- [ ] One special camera move per film, not every shot.
- [ ] No snap zoom, Dutch angle, or handheld shake.
- [ ] Book/stack/prop animation has weight, not linear sliding.
- [ ] No element pops in a frame late.

## Audio

- [ ] VO intelligible at −14 LUFS; music ducked.
- [ ] True peak ≤ −1.5 dBTP (target −1.8).
- [ ] No clipping; no abrupt cut at the end.
- [ ] SFX not stacked more than 3 layers.
- [ ] Brand names pronounced correctly.
- [ ] Captions synced to phrase, not word.

## Technical

- [ ] 1920×1080 or 1080×1920; 30/60 fps.
- [ ] H.264 CRF 16, yuv420p, BT.709.
- [ ] AAC 192 kbps, 48 kHz stereo.
- [ ] No black frames > 0.1 s.
- [ ] No freeze > 0.5 s.
- [ ] Duration matches the brief.
- [ ] 9:16 version recomposed, not cropped.
- [ ] File name and version are clear.

## Final watch

Watch once with sound, once muted, once on a phone.

- Muted: can you follow the story from text + visuals?
- Sound: does the VO carry the argument?
- Phone: is the text readable without squinting?
