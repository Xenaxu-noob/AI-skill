# 适用场景与用户群体

## 一句话

这个 Skill 适合把**一个复杂概念**压缩成 60–90 秒、可配旁白/字幕/音效的**解释型动画短片**。

它卖的不是“动画风格”，而是：

> 让不懂的人在 1 分钟内听懂，并且能批量做多语言/多比例版本。

## 最匹配的场景

### 1. AI / 技术概念解释

适合：

- 大模型、Agent、RAG、推理、训练、上下文窗口、Token、幻觉；
- 面向官网首页、发布会、销售邮件、社媒、展会；
- 受众是“不写代码但要做决策”的人。

为什么匹配：概念抽象，实拍拍不出来；比喻 + 图标 + 旁白最有效。

### 2. 创业公司 / 产品发布

适合：

- 60 秒讲清“我们是谁、解决什么问题、怎么做到”；
- 创始人不出镜；
- 没有预算拍办公室、演员、城市空镜；
- 需要中英双语。

### 3. B2B 销售 / 融资 / 展会

适合：

- 销售邮件里的“点开就看”；
- BP、Demo Day、展台循环；
- 把 20 页 deck 压成 1 条 60 秒视频。

### 4. 媒体 / 视频论文 / 知识内容

适合：

- YouTube、B 站、视频号的知识解释；
- 把长文、报告、新闻事件转成视频；
- 需要系列化、周更、稳定视觉模板。

### 5. 教育与课程

适合：

- 课程开场、章节导览、知识点解释；
- 企业培训、合规、入职 onboarding；
- 需要多语言、低成本更新。

### 6. 品牌 / 公共传播

适合：

- 招募、雇主品牌、CSR、公共政策、公益科普；
- 需要“把一件事讲清楚”，不是“拍一支情绪片”。

### 7. 多语言 / 多平台

适合：

- 一条母版，切 16:9、9:16、1:1；
- 换 VO/字幕做英语、日语、西语；
- 给投放做 5–10 个 hook 版本。

## 用户群体

| 用户 | 真实需求 | 他们买什么 |
|---|---|---|
| AI/SaaS 市场 | 产品太技术，首页/广告讲不清 | 60 秒概念解释 + 多版本 |
| 创始人/CEO | 发布会、融资、销售，不想出镜 | 创始人视角的 company story |
| 内容负责人/知识博主 | 要稳定更新、系列化 | 模板 + 月度产能 |
| 广告/创意 agency | 把 AI explainer 做成产品线 | 可复用的制作系统 |
| B2B 销售/IR | deck 太长，客户不看 | 60 秒 teaser |
| 企业 L&D/内部传播 | 培训、合规、流程变更 | 多语言培训片 |
| 媒体 explainer 团队 | 新闻/报告要可视化 | 快速解释视频 |
| 课程/EdTech | 课程预告、知识点 | 课程导览 + 章节动画 |
| 公益/公共部门 | 预算有限，要讲清政策 | 低成本科普 |

## 购买触发点

- “我有脚本/报告/长文，但没有画面。”
- “不想拍人、场地、演员。”
- “两周内要上线。”
- “要 1 个母版 + 10 个 cutdown。”
- “要系列化，不是单条。”
- “抽象概念拍不出来。”
- “创始人不想出镜。”
- “要投流，前 3 秒必须抓人。”
- “要本地化，换语言就能发。”

## 不适合

- 需要真实情感、演员表演的品牌片；
- 产品 UI 的精确演示（该录屏）；
- 真人证言、探店、生活方式；
- 奢侈品、时尚、喜剧；
- 需要 4K 电影感的广告；
- 医疗、金融等强监管内容的最终合规版（可以做，但必须法务审）；
- 10 分钟以上的深度技术课。

## 快速适配判断

如果以下 4 条里满足 3 条，基本适合：

1. 有一个明确、可一句话说清的核心概念；
2. 没有实拍预算/时间/演员；
3. 需要 60–90 秒，而不是 5–10 分钟；
4. 需要多语言、多比例或系列化。

如果核心是“让人哭/让人向往/让人记住一张脸”，不适合。
